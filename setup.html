Ativar os pedidos no banco

Faça uma vez só, pelo celular mesmo. Leva uns 2 minutos e não mexe nas vendas, produtos nem no caixa: só acrescenta as tabelas de pedidos.

1

Copie o código do banco

Toque no botão amarelo. Vai aparecer “Copiado!”.

2

Abra o editor do Supabase

Entre com a conta do Folha Caixa se pedir. Abre o SQL Editor do projeto do caixa.

Abrir o Supabase ↗
3

Cole e rode

Toque no espaço em branco do editor, segure e escolha Colar. Depois toque no botão verde Run. Deve aparecer “Success. No rows returned”.

Se aparecer um aviso perguntando se quer mesmo rodar, toque em Run this query.
